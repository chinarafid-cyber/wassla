# بنية مشروع وصلة (Wassla) — المرحلة 1

هذا الملف يشرح كيف تم بناء المشروع حتى الآن، وليش اخترنا كل أداة، بلغة مبسّطة.

## الفكرة العامة للمشروع

وصلة منصة ويب تربط بين:
- **أصحاب العلامات التجارية** (أزياء، مكياج، مطاعم ومقاهي، مجمعات سكنية، منتجات غذائية)
- **صناع المحتوى (المؤثرين)**

لإنشاء حملات إعلانية. المنصة تربح عن طريق عمولة نسبة مئوية من كل حملة (لم يتم بناء أي جزء متعلق بالدفع بعد — هذا مخطط لمرحلة لاحقة).

## الأدوات التقنية المستخدمة ولماذا

| الأداة | الاستخدام | لماذا اخترناها |
|---|---|---|
| **Next.js** (App Router) | إطار العمل الأساسي للموقع | يبني الواجهة والسيرفر بمكان واحد، سريع، وله دعم ممتاز من Vercel |
| **TypeScript** | لغة البرمجة | تكتشف الأخطاء قبل ما توصل للمستخدم |
| **Tailwind CSS** | التنسيق والتصميم | يسرّع بناء واجهات جميلة بدون كتابة CSS يدوي كثير |
| **Supabase** | قاعدة البيانات + نظام تسجيل الدخول | بديل جاهز وسهل بدل بناء سيرفر وقاعدة بيانات من الصفر؛ يوفر مصادقة (Auth) جاهزة |

## القرارات التقنية المتخذة

1. **استخدمنا `@supabase/ssr`** بدل مكتبة Supabase العادية، لأنه الأسلوب الموصى به رسميًا مع Next.js App Router — يخلي تسجيل الدخول يشتغل صح سواء في المتصفح أو في السيرفر، وما يخلي المستخدم يطلع بشكل مفاجئ من حسابه.

2. **صفحة `/dashboard` مؤقتة** أضفناها فقط لإثبات أن نظام الدخول يعمل فعليًا (تسجّل دخول → تشوف بريدك الإلكتروني → تقدر تسجّل خروج). في المرحلة القادمة (الملفات الشخصية) بيتم تطويرها لتصير الصفحة الرئيسية لكل مستخدم بعد الدخول.

3. **لم نبني أي شيء متعلق بالدفع أو العمولات** في هذه المرحلة، بناءً على طلبك صراحة.

4. **البريد الإلكتروني يحتاج تأكيد افتراضيًا** — عند إنشاء حساب جديد، Supabase يرسل رسالة تأكيد للبريد قبل ما يقدر المستخدم يسجّل دخول. يمكن تعطيل هذا الخيار مؤقتًا من إعدادات Supabase أثناء التجربة (Authentication → Providers → Email → Confirm email).

## كيف تربط المشروع بحسابك في Supabase

1. افتح مشروعك في supabase.com
2. من القائمة الجانبية: Project Settings → API
3. انسخ القيمتين **Project URL** و **anon public key**
4. افتح ملف `.env.local` في المشروع وحطّهم كذا:

```
NEXT_PUBLIC_SUPABASE_URL=القيمة_اللي_نسختها
NEXT_PUBLIC_SUPABASE_ANON_KEY=القيمة_اللي_نسختها
```

5. أعد تشغيل السيرفر المحلي (`npm run dev`) بعد التعديل.
